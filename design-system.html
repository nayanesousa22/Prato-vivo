// Quick Start
01
Importe as fontes
Adicione Inter via Google Fonts e declare a Tangier com @font-face apontando para tangier/Tangier.otf.
02
Copie os tokens
Cole o bloco :root { ... } acima no seu CSS global. Todos os tokens ficam disponíveis como variáveis CSS.
03
Cores
Fundo --color-bone (#F3F1EB), texto e botões --color-forest (#1A2E22). Cards em branco com borda --color-border-soft.
04
Tipografia
Logo e títulos (h1–h4) em Tangier peso 400, sem negrito nem itálico. Textos, botões e legendas em Inter.
